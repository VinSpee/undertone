Install a firmware

Connect a Donner Pocket X or an M-VAVE BlackBox over USB, choose a firmware and install it from this page, in Chrome or Edge on a computer.

Open the editor

This browser has no Web MIDI. Use Chrome or Edge on a computer (Windows, macOS, Linux, ChromeOS).

1Connect the pedal

Turn the pedal on, plug it in over USB (a data cable) and close any other app using it. The browser asks for MIDI access: allow it.

2Choose a firmware

Each firmware below is a whole firmware for the pedal. The pedal runs one at a time: installing one replaces the one it runs, and this page puts the other back the same way. What each firmware saved on the pedal stays there while the pedal runs another one.

During the install, about 1 to 2 minutes:

  • Do not unplug the pedal or switch it off.
  • Keep this tab open.
  • If the install stops, do not switch the pedal off: reconnect the cable and press Resume.
  • First install over the official firmware: keep your backup (SD card or fm1buddy) at hand.

Nothing is sent before this page has checked the package against its SHA-256 and the firmware the pedal runs, and nothing is written before the pedal has checked it too.

    BlackBox V21 factory sounds

    The V21 firmware file contains no amps, cabinets, or presets. After it boots, verify the factory sounds here. If verification fails, start the Terminal tool in the macOS recovery steps before pressing the USB recovery button.

    !Rescue

    Three ways back, by what the pedal does.

    The pedal restarts in a loop

    1. Tick Rescue mode.
    2. Press Connect in step 1.
    3. Plug the pedal in, or let it restart.

    The install starts by itself as soon as the pedal answers, and the restarts stop. It installs the official file chosen in step 3 if there is one for this pedal, otherwise the first firmware of step 2. If the pedal never answers here, use the rescue kit below.

    The pedal stays in update mode

    Do not switch the pedal off. Unplug the cable, plug it back in and press Connect: the Resume button appears in step 2 and finishes the update.

    The pedal shows a black screen, or this page cannot reach it

    A BlackBox in this state can be restored over USB with no extra hardware, from a Mac or a Windows PC, with the rescue kit. A browser cannot do it: the pedal is then a USB mass-storage device, which browsers keep from web pages on every system. The kit's first run is a read-only check: it saves a full backup of the pedal's flash and writes nothing. The restore runs only once the check has passed.

    How to start it on each system

    After the rescue of a pedal that ran M-VAVE V22 or V23, do not install Gamut or PALETTE on it. Installing writes over the end of the V22/V23 boot loader, and the pedal goes dark again. This installer refuses such a pedal and writes nothing, but older installers do not. Gamut is installed on such a pedal from a computer's Terminal instead, with undertone install from the Undertone repository (see "Gamut on a BlackBox with V22 or V23" in the rescue guide).

    How to run the rescue on your computer

    Unzip the kit. It makes one folder, OpenPocket-rescue-kit. Its command, undertone, writes M-VAVE's official firmware back, and the firmware file must match the firmware the pedal had. It checks the pedal and saves a backup first, and writes nothing until you say yes.

    • Path A. The pedal had M-VAVE V16, V17 or V20, and never V22 or V23. File: BlackBox_020.fwsc.
    • Path B. The pedal had M-VAVE V22 or V23 at any time, or you are not sure. File: BlackBox_023.fwsc.
    • Path C. Both files are refused. Stop, keep the backup, and do not try other files.

    The file goes in the kit's firmware folder; put both there if you are not sure. undertone reads the pedal and uses the file that matches it, and says which file the pedal needs when none does. If the folder holds no .fwsc file, its README.txt says where to get the official file and what to call it.

    On a Mac

    1. Once: install Homebrew from brew.sh and follow the "Next steps" it prints.
    2. Once: in Terminal, install libusb. Type this and press Enter: 
      brew install libusb
    3. Unplug the pedal.
    4. In Terminal, type cd and a space, drag the OpenPocket-rescue-kit folder onto the Terminal window, and press Enter.
    5. Start undertone. Type this, press Enter, then type your Mac password when it asks (nothing shows while you type): 
      ./undertone
    6. Choose "fix a pedal that will not start". When it says it is looking for your pedal, plug the pedal straight into the Mac (no hub).
    7. It checks the pedal and saves a backup in the OpenPocket-rescue folder in your home folder. Keep it. Then it asks before it writes anything: choose Yes, and plug the pedal in again when it is looking for it.
    8. When it says "your pedal is fixed", unplug the cable, switch the pedal off, wait 5 seconds and switch it on.

    On Windows

    The Windows rescue has not been tested on a real pedal yet. Please report on GitHub whether it works for you.

    1. Once: install Python 3 from python.org and tick "Add python.exe to PATH" on its first screen. No driver is needed.
    2. Open the OpenPocket-rescue-kit folder until you see undertone.cmd. Click the address bar at the top of the window and copy the location (Ctrl+C).
    3. Press the Windows key, type cmd, right-click "Command Prompt" and choose "Run as administrator". Use Command Prompt, not PowerShell.
    4. Go to the kit's folder. Type this line with the location you copied pasted between the quotes (right-click pastes), and press Enter: 
      cd /d "C:\path\to\OpenPocket-rescue-kit"
    5. Unplug the pedal.
    6. Start undertone: 
      undertone
    7. Choose "fix a pedal that will not start". When it says it is looking for your pedal, plug the pedal straight into the PC (no hub). If Windows offers to format a drive, click Cancel. Never click Format.
    8. It checks the pedal and saves a backup in the OpenPocket-rescue folder in your user folder. Keep it. Then it asks before it writes anything: choose Yes, and plug the pedal in again when it is looking for it.
    9. When it says "your pedal is fixed", unplug the cable, switch the pedal off, wait 5 seconds and switch it on.

    If it does not work

    • "One more file needed": the pedal had another firmware than the files in the folder. Nothing was written. Put the file it names in the firmware folder and start undertone again. "This pedal needs a closer look" is path C: stop.
    • ERROR about the file: it is damaged or it is not a BlackBox firmware file. Nothing was sent to the pedal.
    • It stops in the middle or says it gave up: start it again. It continues where it stopped.
    • The pedal still does not start: open an issue on GitHub with the text from the window, and keep the backup file.

    Under the hood, undertone runs the kit's rescue tool, tools/uboot_rescue.py, unchanged. undertone rescue does the same as plain lines, for a script; the two lines of earlier kits (RESCUE.bat or sudo python3 tools/uboot_rescue.py, with --package and then --write) still work.
