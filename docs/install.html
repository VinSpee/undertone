How to run the rescue on your computer

Unzip the kit. It makes one folder, OpenPocket-rescue-kit. The tool writes M-VAVE's official firmware back, and the firmware file must match the firmware the pedal had. The first run only checks the pedal and saves a backup. Nothing is written until the second run.

  • Path A. The pedal had M-VAVE V16, V17 or V20, and never V22 or V23. File: BlackBox_020.fwsc.
  • Path B. The pedal had M-VAVE V22 or V23 at any time, or you are not sure. File: BlackBox_023.fwsc.
  • Path C. Both files are refused. Stop, keep the backup, and do not try other files.

The file goes in the kit's firmware folder. If that folder holds no .fwsc file, its README.txt says where to get the official file and what to call it. The lines below are for path B. On path A, type BlackBox_020.fwsc in place of BlackBox_023.fwsc.

On a Mac

  1. Once: install Homebrew from brew.sh and follow the "Next steps" it prints. Then, in Terminal, type brew install libusb and press Enter.
  2. Unplug the pedal.
  3. In Terminal, type cd (with a space), drag the OpenPocket-rescue-kit folder onto the Terminal window, and press Enter.
  4. Type sudo python3 tools/uboot_rescue.py --package firmware/BlackBox_023.fwsc and press Enter. Type your Mac password (nothing shows while you type).
  5. When it says it is waiting for the pedal, plug the pedal straight into the Mac (no hub).
  6. The check passed if you see head [0, 0x4000) matches the image and then a line that starts with Read-only run finished, nothing was written. Keep the backup it saved in the OpenPocket-rescue folder in your home folder.
  7. To restore the pedal, unplug it, type sudo python3 tools/uboot_rescue.py --write --package firmware/BlackBox_023.fwsc, press Enter, and plug the pedal in when it is waiting.
  8. When it says Done, unplug the cable, switch the pedal off, wait 5 seconds and switch it on.

On Windows

The Windows rescue has not been tested on a real pedal yet. Please report on GitHub whether it works for you.

  1. Once: install Python 3 from python.org and tick "Add python.exe to PATH" on its first screen. No driver is needed.
  2. Open the OpenPocket-rescue-kit folder until you see RESCUE.bat. Click the address bar at the top of the window and copy the location (Ctrl+C).
  3. Press the Windows key, type cmd, right-click "Command Prompt" and choose "Run as administrator". Use Command Prompt, not PowerShell.
  4. Type cd /d ", paste the location (right-click), type " and press Enter.
  5. Unplug the pedal. Type RESCUE.bat --package firmware\BlackBox_023.fwsc and press Enter.
  6. When it says it is waiting for the pedal, plug the pedal straight into the PC (no hub). If Windows offers to format a drive, click Cancel. Never click Format.
  7. The check passed if you see head [0, 0x4000) matches the image and then a line that starts with Read-only run finished, nothing was written. Keep the backup it saved in the OpenPocket-rescue folder in your user folder.
  8. To restore the pedal, unplug it, type RESCUE.bat --write --package firmware\BlackBox_023.fwsc, press Enter, and plug the pedal in when it is waiting.
  9. When it says Done, unplug the cable, switch the pedal off, wait 5 seconds and switch it on.

If it does not work

  • REFUSED: the file is for another firmware than the pedal had. Nothing was written. Unplug the pedal and run the check with the other path's file. If both files are refused, you are on path C: stop.
  • ERROR about the file: it is damaged or it is not a BlackBox firmware file. Nothing was sent to the pedal.
  • It stops in the middle or says it gave up: run the same line again. It continues where it stopped.
  • The pedal still does not start: open an issue on GitHub with the text from the window, and keep the backup file.
