The pedal's play screen has a new layout. The preset number is larger (58 px figures) and the label of the selected block stands beside it in large letters, pale while the block is on and grey while it is off. The chain is two rows of keys along a line: a block that is on is a pale key on the line, a block that is off a dark key below it, and a bar under a row marks the selected block; a block picked up to be moved rises above the line in amber. The amp's and the cabinet's names are no longer on the play screen: a block's model is on its page, one PUSH away. The tuner's note is larger (81 px) over a scale with a needle, the footers name each control and what it does (`knob block  push edit`), an overload is a taller amber band with a warning sign, and the update screen shows a dot for each step.
