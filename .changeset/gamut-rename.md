The guitar firmware is now Gamut 1.0b1 (`PocketX_950`, `BlackBox_950`), formerly OpenPocket v43. Its boot screen shows Gamut, its editor and the installer call it Gamut with the version 1.0b1, and the site, the README and the documents use the new name. The sound and the controls are those of v43. The USB device name, the update loader's identity and the package names stay as they were, so this installer, the editor and the original OpenPocket project's installer all still find the pedal; that installer names it OpenPocket v50.
