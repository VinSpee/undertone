OpenPocket is now v43 (`PocketX_943`, `BlackBox_943`), so a pedal running it can be told apart from one running v42. Since v42, the built-in amps and cabinets are gone, the preset store is format 6 and converts a preset saved by an earlier version when it loads, ML Sound Lab's "BEST IR IN THE WORLD" in slot IR1 is the only built-in cabinet IR, and the editor protocol is version 5.
