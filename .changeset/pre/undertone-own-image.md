The one-program undertone now installs an app image of your own, such as a test build or firmware built on Undertone: `undertone install --gamut FILE`, or "a file of my own" in its screens. It takes any BlackBox app image the pedal's boot loader would start and that stays inside the app area, still with the dry run and the typed yes first, and it names an image that is not Gamut's release "custom image, not the release". With no file it still installs Gamut's release.
