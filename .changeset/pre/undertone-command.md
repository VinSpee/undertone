The rescue kit has one command, `undertone`: run it with no options and it walks you through fixing a pedal that will not start, putting Gamut on a pedal or checking a pedal, one short screen at a time, with a drawing of the buttons to hold, and it saves a copy of the pedal and asks before it writes anything. `undertone rescue`, `undertone install` and `undertone check` do the same as plain lines. They run the same rescue and install tools as before.
